Humanize commands Strip /bin/zsh -lc "…" and the ./node_modules/.bin/ prefix, split && chains, and show sed -n '1,260p' X as read X:1‑260.
Changes first File edits always show their path and +added/−removed line counts, or a new badge for new files. The diff is one click away.
Failures loud Non‑zero exits turn red and show the first meaningful output line. Retries of the same intent sit next to each other.
Words are optional Agent notes and reasoning appear as one dim italic line (↳ …) and can be switched off.

How they compare

  • A · Ledger: best for reading step by step what happened. Scales to long threads only with folding and phase headers.
  • B · By file: best for “what did it touch, and was it checked?”. Loses order and cause and effect.
  • C · Phase cards: best overview of a 700-action thread. Needs a reliable phase splitter, which is the risky part to build.
  • D · Swimlanes: best for spotting loops and dead time. Weakest for reading what was actually done.
  • Recommendation: A with C’s phase headers (as drawn in A), plus B as a toggle. Answer with letters, e.g. “A+C” or “A, drop phases”.
